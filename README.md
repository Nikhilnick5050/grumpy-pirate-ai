# 🏴‍☠️ Grumpy Pirate AI — Captain Barnacle's Bad-Mood Bot

A grumpy pirate chatbot that talks like a salty sea captain with zero patience.

## Features
- Fully client-side (no API keys needed)
- Rule-based grumpy pirate responses
- Jokes, treasure hints, weather reports, and pirate wisdom
- Quick-reply chips for instant fun
- Dark pirate-themed UI with animated flag and typing indicator

## Tech
- Vanilla HTML, CSS, and JavaScript
- Google Fonts: Pirata One + IM Fell English

## Run locally
Just open `index.html` in your browser. That's it.

## Deploy
Deployed on Vercel. Push to GitHub and Vercel auto-deploys.
